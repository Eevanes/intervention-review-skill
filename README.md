# Intervention Review Skill · 介入判断

一个从助教系统中提炼的通用 AI Skill，帮助助教、导师和项目负责人根据证据判断何时需要支持、采用多大力度，以及何时复查。

核心方法是六道判断门和 L0–L6 最小介入阶梯：先核对事实与目标差距，再考虑等待代价、自解空间和支持增益。正常进展保持安静；证据不足先核实；需要对外行动时交负责人确认。

## 使用

将 [`intervention-review`](intervention-review/) 目录安装到支持 `SKILL.md` 的 Agent skills 目录，并按宿主的方式调用 `intervention-review`。提供任务目标、授权范围、可核验的近期事实和已有行动，Skill 会返回判断及必要的后续步骤。它本身不提供数据连接、定时扫描、消息发送或记录存储，这些能力取决于宿主和明确授权。

## 来源与边界

由 AI 向善实战营助教系统中的介入判断方法提炼，去除了项目专用的配置、账号和数据。六道门、五类决策和支持阶梯是实践设计，不应视为经过临床验证的评分模型。
